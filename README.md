# Linear-Time Ensemble Clustering with Adaptive Self-Refinement of Clusters

You can directly clone this repo and run `demo_TEAR.m`.
> Notes:
>
> * All datasets used in the experiments are located in the "datasets" folder. 
> * Hyper-parameters `tau` and `lambda` are tunable for better performance.  
> * All of our experiments use the seed `rng(2026)` for re-producing.
